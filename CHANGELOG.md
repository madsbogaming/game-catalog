# Changelog

Big updates to Get on the Game, newest first. Only big updates go here (new features, changes people will notice), not every fix. Write them for the people using the bot: what changed for them, in a few short lines.

Nothing here is posted by itself. Servers that turned on **Bot updates** with `/setup post` get the newest entry only when Mads runs `tools/announce_update.py --post` (see that file).

Each entry starts with `## <date>: <title>`. That heading is how a server remembers it already got an entry, so don't change it once it's been posted.

## 2026-11-04: Game Catalog is open to every server

- **New name.** The bot is now called Game Catalog, with a new look.
- **Add it anywhere.** Any server can add the bot now, and gets a short hello with the setup steps.
- **Your prices and your time.** `/setup country` shows Steam prices in your currency, and `/setup timezone` makes #GOTG and the weekly deals post at your local time.
- **Bot updates.** Pick a channel with `/setup post` → Bot updates to get posts like this one when something new arrives. It's off unless you turn it on.
