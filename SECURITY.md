# Security

Found a way to break or misuse the bot, its catalog page or the data it keeps? Please don't open a public issue or discussion, since everyone can read those.

Instead, [report it privately on GitHub](https://github.com/madsbogaming/game-catalog/security/advisories/new) (the repo's **Security** tab → **Report a vulnerability**). Only Mads sees it. If you can't use GitHub, email [mads.ringgaard@live.dk](mailto:mads.ringgaard@live.dk).

Say what you found and how to repeat it. You'll get an answer within a week.
